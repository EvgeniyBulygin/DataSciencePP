# Отчёт по лабораторной работе №3: линейные модели

## 1. Данные и подготовка

Для линейной регрессии использован `Student_Performance.csv` (10 000 строк, 5 признаков и целевая переменная `Performance Index`). Категориальный признак `Extracurricular Activities` преобразован в числа: `Yes = 1`, `No = 0`. Остальные признаки уже числовые.

Для бинарной классификации использован `german.csv` (1 000 строк, 20 признаков). Файл прочитан с разделителем `;`. Целевая переменная — `Creditability` (классы 0 и 1; положительным считается класс 1).

В обоих экспериментах данные разделены на обучающую и тестовую выборки в отношении 80/20 с `random_state=42`. Для классификации применена стратификация по целевому классу. Масштабирование признаков выполнено через `StandardScaler`, причём параметры масштабирования вычислялись только на обучающей выборке, после чего применялись к тестовой.

## 2. Гипотезы и эксперименты

**Линейная регрессия.** Реализован пакетный градиентный спуск для функции потерь MSE. Перед обучением признаки стандартизированы, а целевая переменная нормирована по среднему и стандартному отклонению для устойчивости оптимизации. Использованы `learning_rate = 0.05` и `epochs = 800`. На обучении нормированная MSE уменьшилась с `1.0000` до `0.01131`.

**Логистическая регрессия.** Реализована сигмоидальная функция и пакетный градиентный спуск по бинарной кросс-энтропии. Использованы `learning_rate = 0.1`, `epochs = 1000`, порог классификации `0.5`. Значение функции потерь на обучении снизилось с `0.69315` до `0.48213`.

Для сравнения использовано то же разбиение данных. Сравнивались собственная логистическая модель, `sklearn.linear_model.LogisticRegression`, `DecisionTreeClassifier` и `KNeighborsClassifier` с `n_neighbors=5`. Для логистической регрессии sklearn установлено `max_iter=2000`, для дерева — `random_state=42`. Признаки масштабировались для логистической регрессии и KNN; дерево обучалось на исходных числовых признаках.

## 4. Выводы

Собственная логистическая регрессия показала качество, практически совпадающее с реализацией sklearn: Accuracy, Precision, Recall и F1 совпали в пределах отображаемой точности, а ROC-AUC отличается менее чем на 0.001. Это подтверждает корректность собственной реализации градиентного спуска.

На данном разбиении логистические модели превзошли дерево решений и KNN по ROC-AUC, Accuracy и F1. KNN показал достаточно высокий Recall, но уступил по общей точности и F1. Дерево решений оказалось худшим из трёх базовых алгоритмов по большинству метрик; вероятная причина — переобучение отдельного дерева на небольшой выборке и отсутствие настройки его глубины.

Линейная регрессия достигла тестовой MSE около 4.08, что означает средний квадрат ошибки прогноза примерно 4.08 единицы в квадрате целевой шкалы.

## 5. Воспроизводимость

Для повторения экспериментов используются `random_state=42`, разбиение 80/20 и стратификация для классификации. Параметры собственных моделей: линейная регрессия — `learning_rate=0.05`, `epochs=800`; логистическая регрессия — `learning_rate=0.1`, `epochs=1000`. Сравнение: KNN с `k=5`, дерево с `random_state=42`, sklearn LogisticRegression с `max_iter=2000`.

Все измеренные значения сохранены в `experiment_results.json`. Запускать эксперименты следует из каталога проекта; необходимы библиотеки NumPy, Pandas и scikit-learn.
